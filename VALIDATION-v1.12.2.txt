METHOD / ENVIRONMENT
Local Linux Chromium/Playwright, actual browser AudioContext/WebRTC/relay packet
processing, synthetic microphone input and keyboard/HID events. The updated
Node server ran against a local PostgreSQL database. Account and weather tests
used controlled data; browser TTS/native speech callbacks were simulated where
required. Desktop and phone-width layouts were checked; radio status placement
was inspected visually. JavaScript syntax checks passed for all npm check
entry points, including the shared radio engine and rider/COMMS scripts.

A browser test fixture initially hit Chromium's local-network access checks;
its page was changed to a genuinely served same-origin page. One parallel
regression run hit an account-gated rider initialization timing race in the test
harness; the rerun waited for rider initialization and passed. Neither issue was
hidden by removing a product assertion. Repeated runs are not double-counted.
